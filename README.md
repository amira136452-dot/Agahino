# آگهینو

پلتفرم فارسی و راست‌چین برای ثبت و مشاهده آگهی‌های خرید، فروش کالا و خدمات.

## مشاهده سایت
https://amira136452-dot.github.io/Agahino/

## وضعیت زیرساخت
- نسخه وب روی GitHub Pages منتشر شده است.
- رابط کاربری فارسی و واکنش‌گرا است.
- پروژه به Supabase متصل است.
- جدول مرکزی `public.ads` با RLS فعال آماده است.
- فضای ذخیره‌سازی `ad-images` عمومی برای مشاهده است؛ بارگذاری، ویرایش و حذف فقط در پوشه اختصاصی هر کاربر مجاز است.
- ورود و ثبت‌نام ایمیلی با Supabase Auth در سایت پیاده‌سازی شده است.
- ورود با شماره موبایل از OTP پیامکی استفاده می‌کند؛ ارسال فعلاً به علت خطای ۴۱۲ کاوه‌نگار (فرستنده نامعتبر) کامل نشده و تیکت پشتیبانی ثبت شده است.

## فایل‌های راه‌اندازی
- `supabase/setup.sql`: راه‌اندازی تکرارپذیر جدول، RLS، Storage و trigger برای پروژه تازه.
- `supabase/schema.sql`: طرح پایه اولیه پایگاه داده.

## کارهای باقی‌مانده پیش از انتشار عمومی
1. دریافت پاسخ کاوه‌نگار و نهایی‌کردن ارسال OTP پیامکی.
2. بررسی URL و redirectهای Auth برای دامنه GitHub Pages.
3. آزمایش ثبت‌نام و ورود ایمیلی و پیامکی.
4. آزمایش ثبت، نمایش، حذف آگهی و بارگذاری تصویر با دو حساب مستقل.
5. فعال‌کردن محافظت رمزهای افشاشده در تنظیمات Auth.
6. بررسی نهایی امنیت، حریم خصوصی و تجربه کاربری.

## امنیت
- کلیدهای `service_role` و `secret` هرگز نباید در مرورگر یا مخزن GitHub قرار بگیرند.
- فقط کلید عمومی publishable در کد سمت مرورگر استفاده می‌شود.
- RLS باید برای تمام داده‌های کاربرمحور فعال بماند.
