# آگهینو

پلتفرم فارسی ثبت و مشاهده آگهی‌های خرید، فروش کالا و خدمات.

## نسخه منتشرشده
https://amira136452-dot.github.io/Agahino/

## وضعیت فعلی پروژه
- وب‌سایت روی GitHub Pages منتشر شده و رابط فارسی و واکنش‌گرا دارد.
- نسخه وب از قابلیت PWA و افزودن به صفحه اصلی اندروید پشتیبانی می‌کند؛ این مورد به معنی انتشار APK یا حضور در کافه‌بازار و مایکت نیست.
- پایگاه داده فعال Supabase است و احراز هویت با شماره موبایل و رمز عبور در کد سایت پیاده‌سازی شده است.
- ورود پیامکی OTP از طریق کاوه‌نگار هنوز وابسته به رفع مشکل فرستنده و پیکربندی است؛ برای ورود با شماره و رمز عبور، تأیید شماره در تنظیمات Auth باید متناسب با روش انتخابی تنظیم شود.
- ثبت آگهی، تصاویر تا سقف ۵ عدد، فیلترها، صفحه جزئیات، گفت‌وگو، پروفایل، گزارش آگهی، پشتیبانی و پنل ناظر در نسخه فعلی کدنویسی شده‌اند.
- وضعیت انتشار آگهی با کنترل پایگاه داده محافظت می‌شود و آگهی جدید وارد صف بررسی می‌شود.
- هوش مصنوعیِ تشخیص محتوای آگهی هنوز به‌عنوان سرویس عملیاتی متصل و اثبات نشده است؛ تا زمان تکمیل و آزمون آن، نباید ادعا شود همه آگهی‌ها به‌صورت خودکار با AI بررسی می‌شوند.
- پرداخت زرین‌پال هنوز فعال نیست؛ امکانات اصلی نسخه آزمایشی رایگان نگه داشته شوند.

## نکات مهم توسعه و امنیت
- فقط کلید عمومی publishable در کد مرورگر مجاز است. کلیدهای service_role و secret نباید در GitHub یا کد سمت کاربر قرار بگیرند.
- RLS باید برای تمام جدول‌های قابل دسترسی از API فعال بماند.
- نقش مدیر/ناظر باید فقط از مسیر امن و با app_metadata تعیین شود؛ user_metadata قابل اعتماد برای مجوزدهی نیست.
- جدول رویدادهای پرداخت عمداً خصوصی و بدون دسترسی مستقیم کاربران باقی می‌ماند.
- هر تغییر ساختاری پایگاه داده باید به‌صورت migration مستند و پس از آزمون انجام شود.

## پیش از جذب گسترده کاربران
1. آزمایش ثبت‌نام و ورود با دو حساب مستقل، بدون اتکا به OTP پیامکی.
2. آزمایش ثبت آگهی، بارگذاری و نمایش ۵ عکس، ویرایش، حذف، علامت‌گذاری فروش و گزارش تخلف.
3. آزمایش گفت‌وگوی دو کاربر و اطمینان از محرمانه‌بودن پیام‌ها.
4. بررسی دسترسی ناظر و مسیر تأیید/رد آگهی.
5. تکمیل و آزمایش واقعی بررسی خودکار محتوا و ارجاع فقط موارد مشکوک.
6. تکمیل دسته‌بندی‌ها و فهرست شهرهای ایران.
7. فعال‌کردن محافظت رمزهای افشاشده در تنظیمات Auth.
8. آماده‌سازی نسخه اندروید برای انتشار در فروشگاه‌های معتبر و بررسی الزامات آن‌ها.

## فایل‌ها
- `index.html`: صفحه اصلی و منطق اصلی وب‌اپ.
- `profile.html`: پنل کاربری.
- `messages.html`: گفت‌وگوی خریدار و فروشنده.
- `admin.html`: پنل ناظر.
- `support.html` و `support-admin.html`: پشتیبانی.
- `supabase/`: فایل‌های SQL و راه‌اندازی اولیه؛ فایل‌های bootstrap قدیمی را روی پایگاه داده فعال بدون بررسی و migration اجرا نکنید.
