# آگهینو

پلتفرم فارسی و راست‌چین برای ثبت و مشاهده آگهی‌های خرید، فروش کالا و خدمات.

## مشاهده سایت
https://amira136452-dot.github.io/Agahino/

## وضعیت فعلی
- نسخه وب اولیه روی GitHub Pages منتشر شده است.
- رابط کاربری واکنش‌گرا و فارسی است.
- پروژه به Supabase متصل شده و جدول مرکزی آگهی‌ها و فضای تصاویر آماده است.
- ثبت، نمایش و مدیریت آگهی در کد به حساب کاربری وابسته است.
- ورود با ایمیل در رابط موجود است؛ ورود پیامکی نیازمند تنظیم ارائه‌دهنده SMS در Supabase است.
- آگهی‌ها در پایگاه داده مرکزی ذخیره می‌شوند، اما تا تکمیل و آزمایش Auth و تنظیمات امنیتی، پروژه برای معاملات واقعی آماده نیست.

## فایل‌های راه‌اندازی
- `supabase/setup.sql`: راه‌اندازی کامل اولیه (جدول، RLS، Storage و trigger).
- `supabase/schema.sql`: طرح پایه پایگاه داده.

## مراحل باقی‌مانده
1. پیکربندی و آزمایش Auth (ایمیل و SMS).
2. بررسی تنظیمات URL و redirect برای GitHub Pages.
3. آزمایش ثبت‌نام/ورود، ثبت آگهی، تصویر، حذف و مالکیت با دو حساب مستقل.
4. فعال‌سازی محافظت رمزهای لو رفته در Auth.
5. بررسی نهایی امنیت، حریم خصوصی و تجربه کاربری قبل از انتشار عمومی.

**امنیت:** کلیدهای service_role/secret هرگز در مرورگر یا مخزن GitHub قرار نگیرند. فقط publishable key در کلاینت استفاده شود.
