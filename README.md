# آگهینو

پلتفرم فارسی و راست‌چین برای ثبت و مشاهده آگهی‌های خرید، فروش کالا و خدمات.

## مشاهده سایت

https://amira136452-dot.github.io/Agahino/

## وضعیت فعلی

- نسخه اولیه با HTML، CSS و JavaScript ساخته شده است.
- طراحی برای موبایل و رایانه واکنش‌گرا است.
- جستجو، دسته‌بندی، مرتب‌سازی و فرم ثبت آگهی در نسخه نمایشی وجود دارد.
- برنامه وب پیش‌رونده (PWA) و پوسته آفلاین اضافه شده است؛ پس از اولین بارگذاری موفق، خود صفحه می‌تواند بدون اینترنت باز شود.
- آگهی‌ها فعلاً فقط در حافظه محلی همان مرورگر (localStorage) ذخیره می‌شوند. بنابراین کاربران دیگر آگهی‌های ثبت‌شده را نمی‌بینند و پاک شدن داده‌های مرورگر ممکن است آگهی‌ها را از بین ببرد.

## مرحله‌های بعدی برای تبدیل به بازار واقعی

1. انتخاب و راه‌اندازی سرویس بک‌اند و پایگاه داده مرکزی.
2. ساخت حساب کاربری، ورود و مدیریت آگهی‌های هر کاربر.
3. ذخیره امن تصاویر آگهی‌ها.
4. اعتبارسنجی سمت سرور، کنترل هرزنامه و گزارش آگهی.
5. آزمایش امنیت، حریم خصوصی و عملکرد پیش از استفاده عمومی.

**توجه:** تا زمان راه‌اندازی بک‌اند و پایگاه داده، این پروژه یک نمونه اولیه است و نباید برای اطلاعات حساس یا معاملات واقعی به آن اتکا کرد.
